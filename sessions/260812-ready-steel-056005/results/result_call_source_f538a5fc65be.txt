#### 6. 结构化数据提取（firecrawl_extract）

利用 LLM 能力从多个页面中提取符合 JSON Schema 的结构化数据：

- 支持自定义 Prompt 和系统提示词
- 支持 JSON Schema 定义输出结构
- 可选启用 Web 搜索获取额外上下文
- 支持子域名包含和外链控制
- 云端使用 Firecrawl 托管 LLM，自托管使用本地配置的 LLM
