## 第 1 周：基础命令 + 电气符号绘制

### Day 1 — 熟悉界面 + 画第一个电阻符号

**目标**：掌握基本操作，画一个电阻符号。

**电阻符号**：矩形框 + 两端引线（国标 IEC 标准）

**步骤**：
1. 新建文件 → `acadiso.dwt` → 保存为 `Day01_电阻.dwg`
2. 输入 `REC` → 画一个 `@600,200` 的矩形（电阻体）
3. 输入 `L` → 从矩形左边中点向左画引线：`@400,0`
4. 输入 `L` → 从矩形右边中点向右画引线：`@400,0`
5. 选中所有 → 输入 `B` → 创建块 → 名称 `RESISTOR` → 基点选左引线端点 → 确定
6. 保存

**🔍 自检步骤**：
1. 按 `Ctrl+A` 全选 → 底部状态栏看对象数量，应为 **3 个**（1个矩形 + 2条引线）
2. 选中矩形 → 按 `Ctrl+1` 看特性面板 → 宽度应为 `600`，高度应为 `200`
3. 用 `DIST` 命令测量左侧引线长度 → 应为 `400`
4. 用 `DIST` 命令测量右侧引线长度 → 应为 `400`
5. 检查是否成功创建块：输入 `I` → 看名称列表里有 `RESISTOR`

### Day 2 — 画电容、电感、二极管符号

**目标**：熟悉基本电气元件符号的画法。

**电容符号**（无极性）：
1. 输入 `L` → 画左侧引线 `@200,0`
2. 输入 `L` → 从引线末端向上画一条竖线 `@0,300`
3. 向右移动 40mm，画第二条竖线 `@0,300`（两平行板）
4. 从第二条板右端画引线 `@200,0`

**电感符号**：
1. 输入 `L` → 画左引线 `@300,0`
2. 画 4 个半圆弧：输入 `A` → 指定起点 → 依次画半圆
   - 更简单方法：用 `C` 画 4 个相邻的小圆 → 用 `TR` 修剪掉下半部分
3. 右端画引线 `@300,0`

**二极管符号**：
1. 输入 `L` → 画左引线 `@200,0`
2. 画三角形：输入 `POL` → `3` → 画三角形（底边 200，高 200）
3. 三角形右侧画一条竖线 `@0,200`
4. 画右引线 `@200,0`

3个符号各做成块保存 → 保存为 `Day02_电容电感二极管.dwg`

**🔍 自检步骤**：
1. **电容**：选中两条竖线 → 按 `Ctrl+1` 看高度 → 都应为 `300`
2. **电感**：选中所有 → 输入 `LIST` → 确认有 4 个圆弧段
3. **二极管**：三角形三条边长度应一致，竖线应在三角形顶点右侧

### Day 3 — 画开关、继电器线圈、接触器符号

**常开开关**：
1. 左引线 `@200,0`
2. 画一个小圆 `C` → 半径 50
3. 从圆心画一条斜向上的线（表示可动触点）`@150,80`
4. 在斜线末端下方画一个小圆（静触点）
5. 右引线

**继电器线圈**：
1. 输入 `REC` → `@400,150`（长方形线圈）
2. 左右各画引线
3. 矩形内标注文字：输入 `MT` → 输入 `KA` 或 `KM`

**接触器主触点**：
1. 画 3 组常开触点（参考 Day 2 的开关画法）
2. 垂直排列，间距 300
3. 左侧用一条虚线连接（表示联动）

保存为 `Day03_开关继电器.dwg`

**🔍 自检步骤**：
1. **继电器线圈**：选中矩形 → 按 `Ctrl+1` → 宽度应为 `400`，高度应为 `150`
2. **接触器主触点**：用 `QSELECT` → 对象类型选"直线" → 确认共有 9 条线（3组×2个触点 + 1条虚线）
3. 检查每个符号旁都有正确的代号标注（SB、KA、KM）

### Day 4 — 画电机、变压器、指示灯符号

**三相电机**：
1. 输入 `C` → 画一个半径 300 的圆
2. 圆内输入 `MT` → 文字 `3~M`（三相电机标识）
3. 圆上方画 3 个接线端子

**变压器**：
1. 左侧画电感线圈（参考 Day 2）
2. 右侧画电感线圈
3. 中间画两条竖线表示铁芯

**指示灯**：
1. 输入 `C` → 半径 100
2. 圆内画一个 `X`（两条对角线）
3. 旁边标注文字：输入 `MT` → `HL`（指示灯代号）

保存为 `Day04_电机变压器.dwg`

**🔍 自检步骤**：
1. **电机**：选中圆 → 按 `Ctrl+1` → 半径应为 `300`
2. **指示灯**：选中圆 → 半径应为 `100`；检查圆内有2条交叉对角线（X形）
3. 用 `AREA` 命令测量电机圆面积 → 应约为 `282743`（π×300²）

## 第 2 周：电气原理图绘制

### Day 8 — 画一个最简单的电机启停控制电路

**电路说明**：三相电机启停控制（自锁电路）

**图纸设置**：
1. 新建文件 → `Day08_启停电路.dwg`
2. 输入 `LA` → 创建图层：
   - `L1-POWER`（主电路）：红色，线宽 0.5
   - `L2-CONTROL`（控制电路）：绿色，线宽 0.25
   - `L3-TEXT`（文字标注）：白色，线宽 0.18
   - `L4-DIM`（尺寸标注）：黄色

**主电路**（切换到 `L1-POWER`）：
1. 画 3 条垂直电源线（L1、L2、L3），间距 400
2. 从上到下依次画：
   - 熔断器 FU1、FU2、FU3（3 个，各对应一条线）
   - 接触器 KM 主触点（3 组常开）
   - 热继电器 FR 主触点（3 组）
   - 三相电机 M（圆圈，底部）
3. 每条线上用 `MT` 标注元件代号

**控制电路**（切换到 `L2-CONTROL`）：
1. 从 L1、L2 引出两条控制电源线（垂直）
2. 从上到下依次串联：
   - 停止按钮 SB1（常闭）
   - 启动按钮 SB2（常开）
   - 接触器 KM 线圈
   - 热继电器 FR 常闭触点
3. 在 SB2 两端并联 KM 的常开辅助触点（自锁触点）

**标注**（切换到 `L3-TEXT`）：
1. 每个元件旁标注代号
2. 顶部标注 `AC380V`、`AC220V`
3. 底部标注 `PE`

保存并检查线路连接是否完整。

**🔍 自检步骤（Day 8 — 启停电路）**：
1. **图层检查**：输入 `LA` → 确认有 4 个图层（L1-POWER、L2-CONTROL、L3-TEXT、L4-DIM）
2. **元件计数**：用 `QSELECT` 统计以下元件数量：
   - 熔断器 FU：主电路 3 个 ✓
   - 接触器 KM 主触点：3 组 ✓
   - 热继电器 FR 主触点：3 组 ✓
   - 电机 M：1 个 ✓
   - 停止按钮 SB1：1 个（常闭）✓
   - 启动按钮 SB2：1 个（常开）✓
   - 接触器 KM 线圈：1 个 ✓
   - KM 常开辅助触点（自锁）：1 个 ✓
   - FR 常闭触点：1 个 ✓
3. **电路连通性**：用 `DIST` 命令检查关键连接点是否真正连接（距离 = 0）
4. **标注完整性**：所有元件旁都有代号（FU1、KM、FR、SB1、SB2 等）
5. **电压标注**：顶部有 AC380V（主电路）和 AC220V（控制电路）
6. **逻辑检查**：自锁触点 KM 是否并联在 SB2 两端？（这是最常见的错误！）

### Day 9 — 画正反转控制电路

**电路说明**：三相电机正反转控制（互锁电路）

**步骤**：
1. 新建文件 → `Day09_正反转.dwg`
2. 主电路：
   - 两个接触器 KM1（正转）、KM2（反转）
   - KM2 的接线需要交换两相（改变相序）
   - 用不同颜色区分三条相线
3. 控制电路：
   - 正转回路：SB2（正转启动）→ KM1 线圈
   - 反转回路：SB3（反转启动）→ KM2 线圈
   - 互锁：KM1 常闭触点串在 KM2 回路中，KM2 常闭触点串在 KM1 回路中
   - 公共部分：SB1（停止）→ FR（热继常闭）
4. 标注所有元件

**🔍 自检步骤（Day 9 — 正反转电路）**：
1. **主电路**：KM2 是否交换了两相？（L1→L2, L2→L1，L3 不变）
2. **互锁检查**：
   - KM1 常闭触点是否在 KM2 线圈回路中？✓
   - KM2 常闭触点是否在 KM1 线圈回路中？✓
   - 这是最关键的！没有互锁会导致短路！
3. **元件计数**：接触器 2 个（KM1、KM2）、按钮 3 个（SB1 停止、SB2 正转、SB3 反转）
4. **自锁**：KM1 和 KM2 是否各自有自锁触点并联在启动按钮两端？

### Day 10 — 画星三角降压启动电路

**电路说明**：大功率电机星三角启动

**主电路**：
1. 接触器 KM（主接触器）
2. 接触器 KMY（星形接触器）
3. 接触器 KM△（三角形接触器）
4. 电机绕组（6 个端子 U1/U2, V1/V2, W1/W2）
5. KMY 将 U2-V2-W2 短接（星形）
6. KM△ 将 U1-W2, V1-U2, W1-V2 连接（三角形）

**控制电路**：
1. 时间继电器 KT
2. KM、KMY、KM△ 线圈及互锁
3. 启动 → KMY + KM 吸合 → KT 计时 → KMY 断开 → KM△ 吸合

保存为 `Day10_星三角启动.dwg`

**🔍 自检步骤（Day 10 — 星三角启动）**：
1. **主电路接触器数量**：3 个（KM 主接触器 + KMY 星形 + KM△ 三角形）
2. **电机接线**：6 个端子（U1/U2, V1/V2, W1/W2）
3. **星形接法**：KMY 将 U2-V2-W2 短接在一起
4. **三角形接法**：KM△ 将 U1-W2, V1-U2, W1-V2 交叉连接
5. **互锁**：KMY 和 KM△ 必须互锁（不能同时吸合！）
6. **时间继电器 KT**：是否在控制电路中？
7. **启动逻辑**：启动时 KM+KMY 吸合 → KT 计时 → KMY 断开 → KM△ 吸合

### Day 13 — 画两台电机顺序启动电路

## 🔍 通用自检验证方法（每天都适用）

### 方法一：用 CAD 自带查询功能自检

| 验证方式 | 命令 | 用途 |
|---------|------|------|
| 测量距离 | `DIST` | 检查你画的线长度对不对 |
| 测量面积 | `AREA` | 检查房间/元件面积 |
| 查看属性 | `Ctrl+1` | 看对象的坐标、半径、长度等属性 |
| 列表信息 | `LIST` | 查看对象的所有详细信息 |
| 清点数量 | `QSELECT` | 快速选择同类对象，数个数 |

### 方法二：关键检查清单

每完成一个练习，问自己：
1. **数量对不对？** 比如启停电路应该有 3 个熔断器、1 个接触器、1 个热继电器
2. **尺寸对不对？** 用 `DIST` 测关键线段长度
3. **连线对不对？** 所有连接点是否真正相交（距离 = 0）
4. **标注全不全？** 每个元件都有代号吗？
5. **逻辑对不对？** 电路是否能正常工作？

### 方法三：用 DIST 验证关键尺寸

**操作步骤**：
1. 输入 `DIST` → 按 `Enter`
2. 捕捉第一个点（比如线的起点）
3. 捕捉第二个点（比如线的终点）
4. 命令行会显示距离、X/Y 差值、角度

**示例验证**：
- Day 8 启停电路中：测量电源线间距 → 应为 `400`
- Day 15 电柜中：测量柜体宽度 → 应为 `800`

## 🔍 各阶段关键自检清单

### 第 2 周原理图自检（Day 8-14）

每次画完一个电路，依次检查：

1. **电源标注** ✓ — 是否有电压标注（AC380V/AC220V/DC24V）？
2. **元件代号** ✓ — 每个元件都有唯一代号吗？
3. **触点状态** ✓ — 常开/常闭是否画正确了？
4. **互锁/自锁** ✓ — 自锁电路有并联触点吗？互锁电路有串联常闭触点吗？
5. **保护回路** ✓ — 有热继电器 FR 和急停按钮吗？

### 第 3 周布局图自检（Day 15-21）

1. **尺寸标注完整** ✓ — 外形尺寸、安装尺寸、区域尺寸
2. **元件不重叠** ✓ — 每个元件之间有足够的间距
3. **线槽连通** ✓ — 左右线槽从上到下贯通
4. **端子编号连续** ✓ — XT1-1, XT1-2... 无跳过
5. **IO 表对应** ✓ — IO 表中的端子号与端子排图一致

### 第 4 周综合项目自检（Day 22-30）

1. **图纸一致性** ✓ — 原理图中的元件在布置图中都有
2. **端子排对应** ✓ — 原理图的每个接线点在端子排图上都有
3. **IO 表对应** ✓ — PLC 接线图与 IO 表一致
4. **电缆清册完整** ✓ — 每根电缆在清册中都有记录
5. **图框标题栏** ✓ — 每张图纸都有图框和标题栏
