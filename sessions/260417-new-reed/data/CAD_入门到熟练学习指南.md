# CAD 入门到熟练 — 系统学习路径

> 本指南适用于 AutoCAD 初学者，从零开始逐步进阶到熟练操作。
> 适用版本：AutoCAD 2020+（各版本界面略有差异，但核心操作一致）

---

## 第一阶段：认识 CAD 与基础操作（1-2周）

### 1.1 什么是 CAD
- CAD（Computer-Aided Design）= 计算机辅助设计
- 用途：建筑设计、机械工程、室内设计、电气布线、工业设计等
- AutoCAD 是最主流的 CAD 软件之一

### 1.2 界面认知
打开 AutoCAD 后，认识以下区域：
- **功能区（Ribbon）**：顶部工具栏，包含所有命令
- **绘图区**：中间的黑色大区域，用于绘图
- **命令行**：底部，输入命令和查看提示
- **状态栏**：底部状态栏，控制捕捉、正交、栅格等
- **坐标系（UCS）**：左下角的 XYZ 坐标指示

### 1.3 鼠标操作
| 操作 | 作用 |
|------|------|
| 左键单击 | 选择对象/指定点 |
| 右键单击 | 确认/快捷菜单 |
| 滚轮缩放 | 放大/缩小视图 |
| 滚轮按住拖动 | 平移视图 |
| 滚轮双击 | 缩放至所有对象 |

### 1.4 第一个命令
```
LINE     → 画直线（快捷键 L）
CIRCLE   → 画圆（快捷键 C）
RECTANG  → 画矩形（快捷键 REC）
ERASE    → 删除对象（快捷键 E）
UNDO     → 撤销（快捷键 Ctrl+Z）
REDO     → 重做（快捷键 Ctrl+Y）
```

### ✅ 练习任务 1：用 LINE 画一个简单房子轮廓

**目标**：画一个长方形房子，宽 8000mm，高 5000mm，带一个三角形屋顶。

**详细步骤**：

1. 打开 AutoCAD，点击「新建」→ 选择 `acadiso.dwt` 模板 → 确定
2. 按 `Ctrl+S` 保存文件，命名为 `练习1_房子轮廓.dwg`
3. **画房子主体（矩形）**：
   - 键盘输入 `L` → 按 `Enter`（启动 LINE 命令）
   - 在绘图区任意位置**单击左键**，确定起点
   - 向右移动鼠标，输入 `8000` → 按 `Enter`（画底边，8000mm）
   - 向上移动鼠标，输入 `5000` → 按 `Enter`（画右边）
   - 向左移动鼠标，输入 `8000` → 按 `Enter`（画顶边）
   - 输入 `C` → 按 `Enter`（Close 闭合，自动连回起点）
4. **画屋顶（三角形）**：
   - 按 `Esc` 取消当前命令（如果有的话）
   - 输入 `L` → 按 `Enter`
   - 移动鼠标到矩形左上角，看到「端点」提示时单击（捕捉左上角）
   - 向上移动鼠标，输入 `3000` → 按 `Enter`（画屋顶左斜边的垂直高度）
   - 向右移动鼠标到矩形右上角，看到「端点」提示时单击
   - 按 `Esc` 退出 LINE 命令
5. **画烟囱**：
   - 输入 `L` → 按 `Enter`
   - 在屋顶右侧某处单击起点
   - 输入 `@0,1500` → 按 `Enter`（画一条竖直线）
   - 输入 `@400,0` → 按 `Enter`（画一条水平线）
   - 输入 `@0,-1000` → 按 `Enter`（画竖直线到屋顶）
   - 输入 `C` → 按 `Enter`（闭合）
6. **查看全图**：双击鼠标滚轮（缩放到所有对象）
7. **保存**：按 `Ctrl+S`

### ✅ 练习任务 2：用 CIRCLE 画几个不同大小的圆

**目标**：画 4 个不同大小的圆，练习多种画圆方式。

**详细步骤**：

1. 新建文件，保存为 `练习2_圆.dwg`
2. **画圆 1 — 指定圆心和半径**：
   - 输入 `C` → 按 `Enter`（启动 CIRCLE 命令）
   - 在绘图区单击确定圆心
   - 输入 `500` → 按 `Enter`（半径 500mm）
3. **画圆 2 — 指定圆心和直径**：
   - 输入 `C` → 按 `Enter`
   - 在第一个圆右下方单击确定新圆心
   - 输入 `D` → 按 `Enter`（切换到直径模式）
   - 输入 `1200` → 按 `Enter`（直径 1200mm）
4. **画圆 3 — 两点画圆（通过两个端点）**：
   - 输入 `C` → 按 `Enter`
   - 输入 `2P` → 按 `Enter`（两点模式）
   - 在绘图区单击第一个点
   - 向右上方移动鼠标，单击第二个点
   - 两个点之间的线段即为直径
5. **画圆 4 — 三切圆（与三条线相切）**：
   - 先画一个三角形：输入 `POL` → 按 `Enter` → 输入 `3` → 按 `Enter` → 单击中心 → 输入半径 `800` → 按 `Enter`
   - 输入 `C` → 按 `Enter`
   - 输入 `T` → 按 `Enter`（切点-切点-半径模式）
   - 单击三角形的一条边（出现「切点」标记）
   - 单击三角形的第二条边
   - 输入 `200` → 按 `Enter`（内切圆半径）
6. 双击鼠标滚轮查看全图
7. 按 `Ctrl+S` 保存

### ✅ 练习任务 3：用 RECTANG 画一个窗户

**目标**：在之前的房子轮廓上添加一个窗户。

**详细步骤**：

1. 打开 `练习1_房子轮廓.dwg`
2. **画窗户外框**：
   - 输入 `REC` → 按 `Enter`（启动 RECTANG 命令）
   - 移动鼠标到房子左侧墙壁附近，单击确定第一个角点
   - 输入 `@1500,1500` → 按 `Enter`（画一个 1500×1500 的正方形窗户）
3. **画窗户十字分隔线**：
   - 输入 `L` → 按 `Enter`
   - 移动鼠标到窗户左边线的中点，当出现「中点」标记时单击
   - 向右移动鼠标到右边线的中点，当出现「中点」标记时单击
   - 按 `Esc` 退出
   - 再次输入 `L` → 按 `Enter`
   - 移动到窗户上边线的中点，单击
   - 向下移动鼠标到下边线的中点，单击
   - 按 `Esc` 退出
4. **用 OFFSET 画窗框厚度**：
   - 输入 `O` → 按 `Enter`（启动 OFFSET 命令）
   - 输入 `50` → 按 `Enter`（偏移距离 50mm，即窗框宽度）
   - 单击窗户外框线 → 再向内侧单击（生成内框）
   - 按 `Esc` 退出
5. 双击鼠标滚轮查看效果
6. 按 `Ctrl+S` 保存

### ✅ 练习任务 4：练习缩放和平移视图

**目标**：熟练使用各种查看操作。

**详细步骤**：

1. 打开之前任意一个练习文件
2. **缩放操作**：
   - 向前滚动鼠标滚轮 → 放大视图
   - 向后滚动鼠标滚轮 → 缩小视图
   - 双击鼠标滚轮 → 缩放到显示所有对象
3. **平移操作**：
   - 按住鼠标滚轮不放 → 拖动鼠标平移视图
   - 输入 `P` → 按 `Enter` → 按住左键拖动 → 按 `Esc` 退出
4. **窗口缩放**：
   - 输入 `Z` → 按 `Enter` → 输入 `W` → 按 `Enter`
   - 在绘图区拖出一个矩形框 → 该区域会放大至全屏
5. **范围缩放**：
   - 输入 `Z` → 按 `Enter` → 输入 `E` → 按 `Enter`（显示所有对象的范围）
6. **上一个视图**：
   - 输入 `Z` → 按 `Enter` → 输入 `P` → 按 `Enter`（回到上一个视图状态）
7. **重生成**：
   - 输入 `RE` → 按 `Enter`（刷新视图，消除锯齿）

## 第二阶段：核心绘图命令（2-3周）

### 2.1 基本绘图命令
| 命令 | 快捷键 | 说明 |
|------|--------|------|
| LINE | L | 直线 |
| POLYLINE | PL | 多段线（连续线段） |
| CIRCLE | C | 圆 |
| ARC | A | 圆弧 |
| RECTANG | REC | 矩形 |
| POLYGON | POL | 正多边形 |
| ELLIPSE | EL | 椭圆 |
| SPLINE | SPL | 样条曲线 |
| HATCH | H | 图案填充 |
| TEXT | T | 单行文字 |
| MTEXT | MT | 多行文字 |
| DIMLINEAR | DLI | 线性标注 |

### 2.2 核心修改命令
| 命令 | 快捷键 | 说明 |
|------|--------|------|
| MOVE | M | 移动对象 |
| COPY | CO | 复制对象 |
| ROTATE | RO | 旋转对象 |
| SCALE | SC | 缩放对象 |
| TRIM | TR | 修剪 |
| EXTEND | EX | 延伸 |
| OFFSET | O | 偏移（复制平行线） |
| MIRROR | MI | 镜像 |
| FILLET | F | 圆角 |
| CHAMFER | CHA | 倒角 |
| STRETCH | S | 拉伸 |
| EXPLODE | X | 分解 |
| ARRAY | AR | 阵列（矩形/环形） |

### 2.3 精确绘图 — 坐标输入
- **绝对坐标**：`100,50` → 以原点(0,0)为基准
- **相对坐标**：`@100,50` → 以上一点为基准
- **极坐标**：`@100<45` → 距离100，角度45度
- **直接距离**：指定方向后直接输入长度

### 2.4 对象捕捉（OSNAP）
按 F3 开关，常用捕捉点：
- 端点（END）、中点（MID）、交点（INT）
- 圆心（CEN）、象限点（QUA）、垂足（PER）
- 切点（TAN）、最近点（NEA）

### ✅ 练习任务 1：绘制一个简单的机械零件三视图

**目标**：画一个轴的三视图（主视图、俯视图、左视图），轴总长 200mm，由三段组成。

**详细步骤**：

1. 新建文件，保存为 `练习3_零件三视图.dwg`
2. **设置绘图环境**：
   - 输入 `UNITS` → 按 `Enter` → 精度选 `0.00` → 确定
   - 按 `F8` 开启正交模式（确保画水平/垂直线）
   - 按 `F3` 开启对象捕捉
3. **画主视图 — 轴的外形**：
   - 输入 `L` → 按 `Enter`
   - 在绘图区偏左上方单击，作为起点
   - 向右输入 `60` → 按 `Enter`（第一段，直径 30mm 的轴段，画的是上边线）
   - 继续向右输入 `80` → 按 `Enter`（第二段，直径 40mm 的轴段）
   - 继续向右输入 `60` → 按 `Enter`（第三段）
   - 按 `Esc` 退出
   - 用 `OFFSET` 画下边线：输入 `O` → 按 `Enter` → 输入 `30` → 按 `Enter` → 选上线 → 向下偏移
4. **画左视图 — 端面圆形**：
   - 在主视图左侧画一个大圆：输入 `C` → 按 `Enter`
   - 单击确定圆心 → 输入 `40` → 按 `Enter`（最大直径 80mm 的端面投影）
5. **画俯视图 — 从上方看**：
   - 在主视图下方画：输入 `REC` → 按 `Enter`
   - 单击起点 → 输入 `@200,80` → 按 `Enter`
6. **添加中心线**：
   - 输入 `L` → 按 `Enter`
   - 从轴的左端画一条水平线贯穿整个轴（右端超出 20mm）
   - 输入 `@-20,0` → 移动鼠标向左 → 输入 `240` → 按 `Enter`
7. **标注尺寸**：
   - 输入 `DLI` → 按 `Enter`（线性标注）
   - 捕捉轴段左端点 → 捕捉第一段右端点 → 向下拖出标注
   - 同样标注其他两段：`80` 和 `60`
8. 按 `Ctrl+S` 保存

### ✅ 练习任务 2：绘制一个带门窗的建筑平面图（客厅+卧室）

**目标**：画一个两房间的建筑平面，客厅 5000×4000mm，卧室 4000×3500mm，墙厚 240mm。

**详细步骤**：

1. 新建文件，保存为 `练习4_建筑平面图.dwg`
2. **画外墙 — 使用多段线**：

   - 在绘图区左下方单击起点
   - 向右输入 `9240` → 按 `Enter`（总宽度 = 5000+4000+240）
   - 向上输入 `4240` → 按 `Enter`（客厅深度 4000 + 墙厚 240）
   - 向左输入 `9240` → 按 `Enter`
   - 输入 `C` → 按 `Enter`（闭合外框）
3. **画内墙 — 用 OFFSET**：
   - 输入 `O` → 按 `Enter` → 输入 `240` → 按 `Enter`
   - 选择外框线 → 向内侧单击 → 四面都偏移
   - 按 `Esc` 退出
4. **画房间分隔墙**：
   - 输入 `L` → 按 `Enter`
   - 从外框底边向上 5240mm 处开始（捕捉底边某点后输入 `@0,4240`）

7. **开窗**：
   - 在外墙面上用 `TR` 剪出一个 1500mm 的窗洞
   - 在窗洞中间用 `OFFSET` 偏移 50mm 画窗框
8. **填充墙体**：
   - 输入 `H` → 按 `Enter`（图案填充）
   - 图案选 `ANSI31`（斜线填充）
   - 比例设为 `10` → 点击墙体区域填充
   - 按 `Esc` 退出
9. 按 `Ctrl+S` 保存

## 第三阶段：图层与属性管理（1-2周）

### 3.1 图层（LAYER）
```
LAYER → 打开图层管理器（快捷键 LA）
```
图层的作用：
- 分类管理不同对象（墙体、门窗、标注、文字各放不同层）
- 统一控制颜色、线型、线宽
- 可单独开关/锁定/冻结

### 3.2 图层最佳实践
| 图层名 | 颜色 | 用途 |
|--------|------|------|
| WALL | 白色/黑色 | 墙体 |
| DOOR | 蓝色 | 门 |
| WINDOW | 青色 | 窗 |
| DIM | 绿色 | 标注 |
| TEXT | 黄色 | 文字说明 |
| HATCH | 灰色 | 填充图案 |
| FURNITURE | 品红 | 家具 |

### 3.3 特性匹配
```
MATCHPROP → 特性匹配（快捷键 MA）
```
将源对象的属性（颜色、图层、线型等）复制到其他对象。

### 3.4 块（BLOCK）
```
BLOCK    → 创建块（快捷键 B）
INSERT   → 插入块（快捷键 I）
WBLOCK   → 写块（保存为独立文件）
```
块的作用：
- 将常用图形（门、窗、家具、标准件）保存为块
- 重复使用，提高效率
- 修改块定义，所有实例自动更新

### ✅ 练习任务 1：为之前画的平面图建立完整的图层体系

**目标**：给 `练习4_建筑平面图.dwg` 中的各个元素分配到正确的图层。

**详细步骤**：

1. 打开 `练习4_建筑平面图.dwg`
2. **打开图层管理器**：
   - 输入 `LA` → 按 `Enter`

- **模型空间**：绘图的地方，按 1:1 实际尺寸绘制

### 5.3 图框与打印
```
PLOT → 打印（快捷键 Ctrl+P）
```

打印设置：
- 选择打印机/PDF输出
- 图纸尺寸（A4/A3/A2/A1/A0）
- 打印比例（1:100, 1:50, 1:20 等）
- 打印样式表（CTB文件，控制线宽和颜色）

   - 向上移动鼠标，用相对坐标定位
2. 用 `L` 画垂直分隔线分隔三个房间
3. 所有内墙用 `OFFSET` 画两侧线（偏移 120mm）

**Step 5 — 开门洞并插入门**
1. 用 `TR` 修剪出门洞（门宽 900mm，距墙端 200mm 处）
2. 切换到 `A-DOOR` 层
3. 用 `L` 和 `A` 画门（900mm 门扇 + 开启弧线）
4. 用 `B` 做成块 → 用 `I` 插到每个门洞

**Step 6 — 开窗户**
1. 用 `TR` 在每面需要采光的外墙上剪出 1500mm 窗洞
2. 切换到 `A-WIN` 层
3. 用 `REC` + `L` 画窗户（双线 + 中间分隔线）

**Step 7 — 布置家具**
1. 切换到 `A-FURN` 层
2. 客厅：沙发（`REC` 画 `@2400,900`）+ 茶几 + 电视柜
3. 主卧：床（`@2000,1800`）+ 床头柜 + 衣柜
4. 次卧：床（`@1500,1200`）+ 书桌
5. 厨房：灶台 + 水槽 + 冰箱
6. 卫生间：马桶 + 洗手盆 + 淋浴区

**Step 8 — 标注与文字**
1. 切换到 `A-DIM` 层 → 标注所有房间尺寸
2. 切换到 `A-TEXT` 层 → 标注房间名称和面积

**Step 9 — 出图**
1. 创建 A3 布局 → 设置视口 1:100
2. 导出 PDF

### 项目二：机械零件图（详细操作步骤）

**目标**：绘制一根传动轴的三视图，标注尺寸和公差。

**轴的规格**：总长 150mm，三段直径分别为 φ30/φ40/φ30，中间段长 60mm，两端各 45mm。

**详细步骤**：

**Step 1 — 新建与设置**
1. 新建文件 → 保存为 `项目二_传动轴.dwg`
2. 输入 `UNITS` → 精度 `0.00` → 确定
3. 输入 `LA` → 创建图层：

   | 图层名 | 颜色 | 用途 |
   |--------|------|------|
   | 粗实线 | 白色 | 轮廓线，线宽 0.5 |
   | 细实线 | 白色 | 尺寸/文字，线宽 0.25 |
   | 中心线 | 红色 | 轴线，线型 CENTER |
   | 虚线 | 黄色 | 不可见轮廓，线型 HIDDEN |

**Step 2 — 画主视图（轴的外形）**
1. 切换到「粗实线」层
2. 画上半部分轮廓：
   - 输入 `L` → 在左侧起点
   - 向右 `45` → 输入 `@40,0`（左轴段上边线）
   - 向上 `5`（从 φ30 到 φ40 的台阶：`@0,5`）
   - 向右 `60`（中间粗段：`@60,0`）
   - 向下 `5`（台阶下来：`@0,-5`）
   - 向右 `45`（右轴段：`@45,0`）
3. 画下半部分轮廓（对称）：
   - 用 `MIRROR` → 输入 `MI` → 选上半部分 → 指定轴线 → 确定镜像
4. 画中心线（切换到「中心线」层）：
   - 画一条贯穿全长的水平点划线

**Step 3 — 画左视图（端面）**
1. 在主视图左侧画圆：输入 `C` → 输入直径 `40`
2. 画中心十字线

**Step 4 — 标注尺寸**
1. 切换到「细实线」层
2. 标注长度：`DLI` 标注 `45`、`60`、`45`
3. 标注直径：输入 `DDI` → 单击圆 → 拖出标注
4. 标注总长：连续标注 `45+60+45=150`

**Step 5 — 标注公差与粗糙度**
1. 双击直径标注 → 在文字前输入 `%%c`（显示 φ 符号）
2. 输入 `MT` → 在轴段旁写 `φ30h7`、`φ40k6` 等公差标注
3. 用 `LE`（引线）标注表面粗糙度符号

**Step 6 — 标题栏**
1. 在图框右下角画标题栏
2. 填写：零件名称「传动轴」、材料「45钢」、比例「1:1」、数量「1」等

### 项目三：电气布线图（详细操作步骤）

**目标**：基于项目一的平面图，绘制室内电气布线图。

**详细步骤**：

**Step 1 — 准备底图**
1. 打开 `项目一_三室一厅平面图.dwg`
2. 另存为 `项目三_电气布线图.dwg`
3. 关闭家具层（`A-FURN`）和填充层（`A-HATCH`）

**Step 2 — 新建电气图层**
1. 输入 `LA` → 创建：

   | 图层名 | 颜色 | 用途 |
   |--------|------|------|
   | E-LAMP | 黄色 | 灯具 |
   | E-SWITCH | 红色 | 开关 |
   | E-SOCKET | 蓝色 | 插座 |
   | E-WIRE | 品红 | 电线 |
   | E-LEGEND | 白色 | 图例 |

**Step 3 — 画灯具**
1. 切换到 `E-LAMP` 层
2. 每个房间中心画一个圆：输入 `C` → 半径 100
3. 卫生间画防潮灯（圆内加十字线）
4. 厨房画吸顶灯

**Step 4 — 画开关**
1. 切换到 `E-SWITCH` 层
2. 每个门旁画开关符号：
   - 画一个小圆 `C` → 半径 50
   - 从圆心画一条短斜线
3. 用 `MT` 在开关旁标注「S」（单控）或「S2」（双控）

**Step 5 — 画插座**
1. 切换到 `E-SOCKET` 层
2. 每个房间墙角画插座：
   - 普通插座：`REC` → `@150,150` → 内画一横线
   - 空调插座：同上 → 内画「AC」字样
   - 厨房插座：标注「厨房专用」
3. 卫生间画防水插座

**Step 6 — 画电线**
1. 切换到 `E-WIRE` 层
2. 用 `PL`（多段线）画电线走向：
   - 从门口配电箱出发 → 到各房间
   - 开关到灯用虚线连接
3. 设置线型：输入 `LTSCALE` → 调整使虚线清晰

**Step 7 — 画图例说明**
1. 切换到 `E-LEGEND` 层
2. 在图面空白处画图例表：
   - 画一个矩形框
   - 列出每个符号及其含义
   - 如：○ = 吸顶灯，⊗ = 防爆灯，—○— = 单控开关
