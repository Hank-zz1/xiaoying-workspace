# 海尔科创生态园3D可视化实现计划

## 概述
使用 Three.js 创建一个精细的海尔科创生态园3D交互式可视化场景，可在浏览器中查看。

## 园区数据（基于公开信息）
- **位置**：青岛市崂山区海尔路1号
- **总占地面积**：1100亩（约73万平方米）
- **二期总建筑面积**：38.5万平方米，可容纳1.2万人
- **主要建筑**（二期）：
  1. 中央研究院 - 核心研发大楼
  2. 食联生态创新中心
  3. 食联生态实验大楼
  4. 衣联&水联生态创新中心
  5. 空气生态创新中心
  6. 空气实验大楼
  7. 其他配套楼座
  8. 员工阳光餐厅

## 技术方案

### 技术栈
- **Three.js** - 3D渲染引擎
- **OrbitControls** - 相机控制（旋转、缩放、平移）
- 纯HTML/JS，无需构建工具，直接浏览器打开

### 场景元素

#### 1. 地形与环境
- 园区地面（带纹理的平面）
- 天空盒/渐变背景
- 光照系统（环境光 + 方向光模拟太阳）
- 阴影效果

#### 2. 建筑群
每栋建筑使用精细的BoxGeometry，包含：
- 建筑主体（带颜色区分）
- 窗户纹理（程序化生成）
- 楼层分隔线
- 建筑标签（CSS2DRenderer或Sprite）
- 建筑高度差异化（基于功能估算）

建筑尺寸估算（基于总建筑面积38.5万平米/7栋楼主楼）：
- 中央研究院：约80m×40m×60m（高层，约15层）
- 各创新中心：约60m×35m×45m（约10-12层）
- 实验大楼：约50m×30m×35m（约8层）
- 员工餐厅：约40m×30m×15m（3-4层）

#### 3. 道路系统
- 主干道（灰色带标线）
- 次干道
- 人行道

#### 4. 绿化景观
- 树木（程序化生成的简单树模型）
- 草坪区域
- 花坛

#### 5. 其他设施
- 停车场
- 广场
- 水景/喷泉

#### 6. 交互功能
- 鼠标旋转/缩放/平移
- 建筑悬停高亮
- 建筑点击显示信息面板
- 视角预设（鸟瞰、人行视角等）
- 昼夜切换
