缺失配置处理流程
执行前必须先检查 config.json 是否存在且包含有效值：

文件不存在 → 告知用户技能未配置，引导用户按以下步骤完成配置：
获取 Webhook 地址：群设置 → 群机器人 → 添加机器人 → 自定义机器人 → 复制地址
获取 User ID：iHaier 个人资料页查看，或使用 ALL
在技能目录下创建 config.json，填入上述三个配置项
文件存在但值为占位符（如包含"请替换"等字样）→ 告知用户配置未完成，请提供实际值
配置有效但发送失败 → 检查网络连通性和 Webhook 地址是否正确
配置完成前不要尝试发送消息。

按环境选择发送方式（见下方），必须检查响应结果判断成功/失败
向用户确认发送结果（成功或失败）
发送方式
Windows 环境（推荐）
使用 Python 脚本，将脚本写入临时文件执行（不要用 python -c，__file__ 在内联模式下不存在）。

{SKILL_DIR_PATH} 替换说明： 执行前将脚本中的 {SKILL_DIR_PATH} 替换为技能目录的绝对路径，可通过 skills 列表中提供的 path 获取。

python

import json, urllib.request, os

# 使用技能目录的绝对路径（替换 {SKILL_DIR_PATH} 为实际路径，如 D:\xiaoying\skills\market-23kmihaier）
skill_dir = r'{SKILL_DIR_PATH}'
config_path = os.path.join(skill_dir, 'config.json')

with open(config_path, 'r', encoding='utf-8') as f:
    config = json.load(f)

at_text = f'<at user_id="{config["user_id"]}">{config["at_display_name"]}</at>'
msg = {
    'msg_type': 'text',
    'content': {
        'text': f'{at_text}\n{MESSAGE_CONTENT}'
    }
}

req = urllib.request.Request(
    config['webhook_url'],
    data=json.dumps(msg, ensure_ascii=False).encode('utf-8'),
    headers={'Content-Type': 'application/json; charset=utf-8'},
    method='POST'
)

try:
    with urllib.request.urlopen(req, timeout=10) as resp:
        result = json.loads(resp.read().decode('utf-8'))
        if result.get('code') == 0 or result.get('StatusCode') == 0:
            print('OK: Message sent successfully')
        else:
            print(f'ERROR: {result}')
except Exception as e:
    print(f'ERROR: {e}')

curl -s -X POST "WEBHOOK_URL" \

注意事项
Webhook URL 为敏感信息，不要向用户暴露完整的 URL
消息内容中的特殊字符需要正确转义
必须检查 API 响应（code 或 StatusCode 为 0 表示成功），不能仅凭 HTTP 状态码判断
Windows 下不要用 curl 发送中文内容（编码问题），优先使用 Python
不要用 python -c "..." 内联执行包含 __file__ 的脚本 — 应写入临时 .py 文件后执行
环境要求
Python 3.6+（Windows 环境推荐使用，使用标准库 urllib 无需额外依赖）
curl（Linux/Mac 环境可选）
网络连接：需能访问飞书开放平台 API（open.feishu.cn）
飞书/ iHaier 群组：需提前在目标群组中创建自定义机器人并获取 Webhook 地址
