# 海外冰箱竞品雷达

独立运行的海外冰箱市场竞品监控智能体。与现有澳洲冰箱定时监控任务**完全隔离**，使用独立的基线文件、数据目录和飞书 Webhook。

## 核心能力

1. **竞品动态查询**：按品牌/区域/时间范围查询竞品新品、价格、促销
2. **多品牌对比分析**：一键生成多品牌竞品对比报告
3. **即时推送**：查询结果通过飞书 Webhook 推送通知

## 监控品牌

- 海信 (Hisense)
- 美的 (Midea)
- 三星 (Samsung)
- LG
- 西屋 (Westinghouse)
- 其他按需添加

## 数据隔离

- 所有数据文件存储在 `data/overseas-fridge-radar/` 目录下
- 与现有 `data/au-fridge-*` 文件完全独立
- 使用独立的飞书 Webhook（需用户配置）

## 使用方式

用户通过自然语言触发，例如：
- "帮我查一下澳洲冰箱市场最近有什么新品"
- "对比三星和LG最新冰箱型号"
- "生成一份海外冰箱竞品周报"

## 工作流程

1. 接收用户查询意图
2. 使用 web_search / ai_search 搜索目标品牌最新动态
3. 使用 firecrawl 抓取关键页面详情
4. 整理并结构化输出分析结果
5. 可选：通过飞书 Webhook 推送

## 注意事项

- 本技能独立运行，不影响现有澳洲冰箱定时监控
- 所有搜索结果均为实时获取，不依赖预存基线
- 首次使用请确认飞书 Webhook 地址
